# DECISIONS

## 2026-09-27 — Session 1
- Primary user is the driver; the passenger map is the second screen that proves value (Blueprint condition 2).
- Pilot route: Chalco – Calzada Ignacio Zaragoza, inbound only. 9 stops, 4 segments. All geometry SIMULATED.
- Voice to report (eyes stay on the road); confirmation only while stopped (GPS gate). Typing fallback only while stopped.
- Drafts live only on the phone; nothing is stored until the driver confirms.
- GPS used live to decide moving/stopped and to suggest the nearest segment. Never stored.
- No police-checkpoint category: if mentioned, the report can only be published as a delay without the cause (condition 5).
- Passengers see only type + segment + stops via `get_public_notices()`; no driver id, name or transcript.
- Confirmation = 2 or more distinct reporters for the same segment + type within the active window. Expiry: 2 hours.
- Demo peer reports are generated by `simulate_peer_report()` and labeled on screen.
- ML: naive Bayes on labeled simulated phrases (ES + EN) + place-name gazetteer. Output shown as "model estimate"; driver always confirms or corrects.
- Money model (not built): free for drivers; government pays for aggregated route data; any payout goes to the whole route, never per report.
